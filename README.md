# Nikhil Kajota — AI & Systems Engineer Portfolio

A modern, high-end editorial portfolio website engineered with the exact visual language, dark obsidian aesthetic, and technical depth of [Dev Chiniwala's portfolio](https://devchiniwala.vercel.app/).

## 🚀 Live Local Development

The development server is running locally:
```bash
npm run dev
# Running on http://localhost:3000/
```

To build for production:
```bash
npm run build
```
